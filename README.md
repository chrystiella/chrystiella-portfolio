# Chrystiella Mensah — Portfolio

A responsive, static portfolio for Chrystiella Mensah, a cybersecurity student at Stevens Institute of Technology.

## Run locally

Open `index.html` in a browser, or serve the project directory with a local web server.

## Files

- `index.html` — portfolio content and navigation
- `style.css` — responsive layout and visual styling
- `profiles.jpeg` — profile photo
- `resume.pdf` — cybersecurity student analyst resume available to download
